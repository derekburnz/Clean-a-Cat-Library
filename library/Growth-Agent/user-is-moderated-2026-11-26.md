# Open Cloud 403 "User is moderated" (2026-11-26 ET, Growth-Agent, read only)
Sources read today. OFFICIAL = Roblox docs. DEV = forum posts. Nothing changed anywhere.
- OFFICIAL (create.roblox.com/docs/cloud/auth/api-keys): a key's access is set by the user who owns it. Status "User Moderated" means "The account that generated the key is under moderation by Roblox"; the fix given is "Resolve the moderation issue on the account." A Roblox admin can also mark a key "Moderated" (secret changed): regenerate the key. A group key shows "Revoked" if its creator loses group key rights. Keys unused 60 days expire. The introspect endpoint (POST api-keys/v1/introspect) says if the key or its last generating user is moderated: read only and safe to run.
- Which account for a group key: the account that generated the key (the "last generated user"). The docs recommend a separate alternate account for group automation. The docs do not describe group-owned keys; a forum announcement says they are deprecated.
- Typical causes (DEV): even a moderation WARNING (an old asset, one case from 2015) broke Open Cloud for the key creator until the warning was confirmed, and Roblox staff said it is inherited behaviour, no timeline (devforum.roblox.com/t/account-moderation-restricts-open-cloud-access/2423437, 2023). In April 2026 service accounts that hold keys were locked as "suspicious" (devforum.roblox.com/t/.../4565510); a June 2026 reply says requests with API keys now keep working when an account is locked for suspicious activity (poster's reply, staff status unconfirmed).
- Duration: no stated length anywhere I read. A warning clears when the owner confirms it.
- What the owner can do (JUDGMENT from the above): look at the account's notifications and moderation history at roblox.com (the key creator account, which Derek knows; memory says OWNER_KEY and a group key), confirm or appeal any warning, then retry. If a key shows "User Moderated" in Creator Hub, resolve it; if the creator account stays restricted, make a new key from a clean account that is a group member with limited rights (docs path).
