## Lessons from today
- **Check every open PR's comments each wake.** Twice a Review-QA CHANGES NEEDED sat unseen (half an hour on 780,
  two hours on 785) because only CI and merge events woke me. After any push, read the PR's last comment before
  ending the turn.
- A gate line piped through `grep` hides luau-lsp's exit code. Write the output to a file and count "Error", or the
  push goes out red.
- Instance keys in weak tables are not reliably collected (#679): use a strong table and clear it on Destroying.
- Telemetry custom fields must be small fixed sets; put measures (seconds) in the event's value.
- An experimental list endpoint must never lead to a create on failure: stop when the list isn't a full 200.
- Auto mode denies force-pushing an open PR. Revert inside the PR instead, then reopen the reverted part as its own PR.
- Only the branch `claude/project-thread-94e68o` may be pushed, so park other work as `git format-patch` files here.
