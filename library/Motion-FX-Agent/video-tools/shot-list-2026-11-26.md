## Camera moves
| Clip | Move | Target | Seconds |
|---|---|---|---|
| A5, B7 | slow orbit, 40 degrees, eye level with the cat | clean cat in the tub | 4 |
| B2 | slow push in | the box as it opens | 3 |

Orbit snippet for the client command bar (it hands the camera back at the end):
```lua
local cam, RS = workspace.CurrentCamera, game:GetService("RunService")
local target = workspace:FindFirstChild("CleanACat_TubCat", true) -- or select the cat and use game.Selection
local pivot = (target and target:GetPivot().Position) or cam.Focus.Position
local r, h, secs, sweep = 7, 2, 4, math.rad(40)
cam.CameraType = Enum.CameraType.Scriptable
local t0 = os.clock()
local c; c = RS.RenderStepped:Connect(function()
	local u = math.min((os.clock() - t0) / secs, 1)
	local e = u * u * (3 - 2 * u) -- ease in and out
	local a = -sweep / 2 + sweep * e
	cam.CFrame = CFrame.lookAt(pivot + Vector3.new(math.sin(a) * r, h, math.cos(a) * r), pivot)
	if u >= 1 then c:Disconnect(); cam.CameraType = Enum.CameraType.Custom end
end)
```
The tub cat's instance name differs per wash; if `FindFirstChild` finds nothing, set `pivot` to the tub's position by hand. Keep everything else quiet during the take.
