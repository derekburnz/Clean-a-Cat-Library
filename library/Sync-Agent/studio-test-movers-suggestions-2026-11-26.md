# Tools that could help Studio test runs stop getting stuck on walls (suggestions only, nothing installed), 2026-11-26
Already reviewed and picked earlier (memory tools-deep-dive): Roblox's Studio skills, roblox-dev-skill, UI and input guides; Chrrxs Studio MCP is PARKED (Derek unsure). Not repeated here as new.
Facts read from the pages (Haiku web read, 2026-11-26; "not stated" means the page is silent):
1. Roblox's built-in Studio MCP server (https://create.roblox.com/docs/studio/mcp). Already in use through our Studio session. It has character_navigation (moves the player to a position or instance path, speed multiplier), user_keyboard_input, user_mouse_input, screen_capture, start_stop_play, execute_luau, get_console_output, subagent (explore, playtest). Wall avoidance or stuck detection for character_navigation: not stated. Free, part of Studio.
2. Roblox Studio Playtest Agent (beta, https://devforum.roblox.com/t/studio-beta-studio-assistant-mcp-playtest-agent/4566767). A playtest subagent that spawns a test character and runs a scenario, returning Pass, Fail, Inconclusive or Error plus a report. It has loop detection (ends a test after several identical tool calls) and a 50-turn limit, but that ends a test early rather than getting unstuck. Early feedback says it sometimes teleports itself instead of navigating. Beta feature, daily usage cap. Worth trying for first-5-minutes smoke tests, not as a fix for sticking.
3. RbxSync bot tools (https://docs.rbxsync.dev/bot-testing and /ai-testing). bot_move uses PathfindingService to a position or an object name, bot_observe type="nearby" lists obstacles, bot_action does equip, activate, interact, jump, bot_wait_for waits for a condition. It says it has stuck detection (method not described), about 500 studs before recompute, cannot climb trusses. Needs the RbxSync server plus a Studio plugin and Allow HTTP Requests on. License not stated on the docs page. This is the closest match to "walk to a named spot without sticking".
4. nonlooped roblox-suite roblox-mcp skill (https://nonlooped.github.io/roblox-suite/skills/roblox-mcp). Setup documentation for the official Studio MCP; no movement logic. Parked line (roblox-suite) from the earlier deep dive.
5. AshExplained roblox-skills, roblox-playtest-qa (via https://enterprisedna.co/directories/skills/roblox-playtest-qa). 34 skills, MIT per the listing, last push 141 days ago, one maintainer, directory score 33/100, no movement method stated. Not recommended.
6. Roblox PathfindingService itself (https://create.roblox.com/docs/characters/pathfinding). Free and in the engine, and what our own helper should use (agent radius, height, CanJump, waypoint timeouts). SimplePath (https://devforum.roblox.com/t/1196762) wraps it with blocked and stuck events; a module, not a skill.
Not read (page failed): cynisca roblox-mcp test automation on lobehub.
Recommendation: build our own small walkTo helper on PathfindingService with a stuck check and a named-spot table (the Studio session is building and testing it now), and optionally try RbxSync's bot_move on one run to compare. Do not install anything until Derek says.
