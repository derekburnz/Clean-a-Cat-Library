## 5. Lessons from this run
- **Weak-keyed Instance tables are unreliable (#679).** Ask for a strong table plus an explicit clear (`Destroying:Once`, or a sweep of entries no longer under `game`). This was caught in 762 and 785.
- **A switch that gates a module-level flag must be wired.** On 775 the new `allowMusic` was never called, and the switch call overwrote the player's own settings. Grep for every caller of a new function.
- **Custom analytics fields must be small fixed sets.** Measures such as seconds go in the event's value (780).
- **A secret saved in the experience gets a domain** (769). A full-access key with no domain could be sent anywhere by a backdoored free model.
- **Experimental APIs that create things** must stop when the list call fails, or they make a duplicate on every run (777).
- **R15 legs don't collide,** so a jump lifts the root to about y 9.8. Wall tests need a moving jump, and gate slabs are 12 studs.
- **Two PRs that both add a switch** can each pass and still break main with a duplicate key (747 plus 754 added buildWindow twice). After such a merge, check main's lint.
- **Derek's own words are the only approval.** A thread's or the coordinator's note never is.
